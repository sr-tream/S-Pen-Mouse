# S Pen Mouse

Android-приложение для Samsung S Pen и Shizuku, без root. Проверено на Galaxy S24 Ultra (SM-S928B), Android 16.

## Использование

1. Запустите Shizuku и разрешите доступ приложению S Pen Mouse.
2. Разрешите показ поверх других приложений: он нужен для служебного приёмника, который подавляет Air Actions без отключения Bluetooth. Дополнительную видимую стрелку можно выключить для игр со своим курсором.
3. Отметьте нужные приложения и включите эмуляцию.
4. Hover перемещает курсор под кончиком пера. Касание удерживает левую кнопку до отрыва. Кнопка пера удерживает правую кнопку до отпускания. Обе кнопки могут быть нажаты одновременно.
5. Для проверки откройте встроенный тест. Он показывает тип событий, кнопки и перетаскивание.
6. Остановить эмуляцию можно переключателем или действием в уведомлении.

Кнопка пера работает в пределах досягаемости экранного дигитайзера. Air Actions по Bluetooth вне этой зоны не используются как мышь.

Во время эмуляции временно отключаются вызов Air Command кнопкой, двойное касание с пером и Samsung hover-подсказки. Общий выключатель Air Actions не меняется: он управляет Bluetooth-связью S Pen. Службе Samsung передаётся состояние hover через отдельный прозрачный приёмник; выбранные приложения получают мышиные события. После выхода служебный hover завершается и настройки восстанавливаются. Если доставка служебного hover не подтверждается, мышь продолжает работать, а приложение показывает предупреждение о недоступности подавления Air Actions.

Отдельный процесс восстановления следит за завершением Shizuku-сервиса. Журнал в /data/local/tmp позволяет восстановить настройки после перезагрузки при следующем запуске эмуляции. Старый журнал 0.1.1 тоже поддерживается: при восстановлении он возвращает выключенный той версией Air Actions.

Версия 0.1.6 проверена на подключённом S24 Ultra: hover, ЛКМ, ПКМ и перетаскивание приходят как SOURCE_MOUSE / TOOL_TYPE_MOUSE; в тесте нет нативных событий пера. Пользователь подтвердил удержание ПКМ без ассистента/меню S Pen и сохранение связи после отдаления пера и выхода из теста. Игры и другие прошивки Samsung требуют отдельной проверки.

## Сборка на Windows ARM64

Требуются JDK 17, Android SDK 36 и NDK r26d с рабочим компилятором для Windows ARM64. По умолчанию используется путь C:\Users\SR_team\Projects\android-ndk-r26d. SDK берётся из %LOCALAPPDATA%\Android\Sdk.

В PowerShell выполните:

```powershell
.\build.ps1
```

Для другого расположения инструментов:

```powershell
.\build.ps1 -SpenNdkPath 'D:\android-ndk' -SpenSdkPath 'D:\Android\Sdk'
```

Сначала компилируются JNI-библиотека и процесс восстановления. Затем Gradle собирает подписанный тестовый APK в app/build/outputs/apk/debug/app-debug.apk. Если локального debug.keystore нет, скрипт создаёт его при первой сборке. Ключи подписи исключены из Git и публичных архивов; сохраняйте свой локальный ключ для последующих обновлений. APK, подписанный другим ключом, нельзя установить как обновление APK из релиза.

Проект можно открыть в Android Studio. Готовые ARM64-библиотеки включены в app/src/main/jniLibs; после изменения C-кода запустите build-native.ps1 до сборки APK в IDE. Библиотеки поддерживают выравнивание 16 KiB.

## Устройство проекта

- MainActivity: выбор запускаемых приложений, разрешения и параметры стрелки.
- MouseService: уведомление, подключение к Shizuku, видимый курсор и прозрачный приёмник служебного hover.
- PenUserService: определение приложения на переднем плане и инъекция SOURCE_MOUSE / TOOL_TYPE_MOUSE, ограниченная UID выбранного приложения.
- input.c: автоматический поиск sec_e-pen, эксклюзивный захват evdev, создание идентификатора мыши через uinput.
- guard.c: временное подавление действий Samsung и восстановление исходных значений.
- TestActivity: ручная и автоматическая проверка мыши.

Служебный приёмник занимает 2 × 2 пикселя в центре экрана. Мышиные события в этой точке смещаются на 3 пикселя, чтобы не попадать в приёмник. Служебные события не содержат нажатий; мышиные нажатия ограничены UID выбранного приложения. Приёмник подтверждает доставку через Binder; состояние hover автоматически истекает у Samsung, если обновления прекращаются. Приложения, которые скрывают сторонние overlay-окна, могут блокировать подавление Air Actions.

Приложение не запрашивает доступ к сети, Accessibility или статистике использования. Для других моделей нужны доступ shell к evdev/uinput и совместимый драйвер пера; они пока не проверялись.

Shizuku API 13.1.5: https://github.com/RikkaApps/Shizuku-API (MIT). AndroidX Annotation 1.3.0: https://developer.android.com/jetpack/androidx/releases/annotation (Apache 2.0).
